## 왜 Moments에 맞나
1. 50초 구조를 그대로 옮길 수 있다: 사람 인트로 → 드롭에서 UI 등장 → 기능 5개 → 사람 반응 → 제품명 → 검정 엔드카드.
2. 4.6–38s가 앱 UI다. 카피도 앱 안의 오브젝트(문서, 스티키 노트, 타이핑 문장)로 나온다. Moments의 검색 입력과 댓글이 같은 문법이다.
3. 33.9–37.8s에 "타이핑 → 완성 → 반응 컷 → 선택 하이라이트" 비트가 있다. AI 검색 데모에 그대로 대응한다.
4. 다른 점: 레퍼런스는 밝은 맥시멀 콜라주다. 리듬과 구조만 가져오고, 색과 밀도는 덜어낸다.

## 음악과 편집
- 템포는 약 103.5 BPM(라이브라 100.5–105 사이에서 흔들림). 구간 구성:
  - 0–3.5s 인트로: 리듬 섹션 없음.
  - 3.5–4.2s: 거의 무음.
  - 4.56s 드롭: 0.5초 사이 저역 +27 dB. 첫 UI 풀프레임 컷이 여기에 맞는다.
  - 4.6–41s 그루브: 음량 평평.
  - 41–42.4s 스톱: 킥 빠짐. 제품명이 떠 있는 동안 컷하지 않는다.
  - 43.2s 재진입 히트에 "with M5".
  - 45s부터 무음 엔드카드.
- 곡이 16분음마다 소리가 있어서, 아무 시점이나 잡아도 87%가 온셋에 걸린다. "컷이 다 박자에 맞는다"는 의미가 없다. 의미가 있는 패턴은 셋이다.
  1. 가장 큰 공개 장면을 가장 큰 히트에 둔다: top accent 14개 중 7개(우연 기대값 3.7개). 드롭 ↔ 첫 UI, "UP TO 9X", 배터리, 512GB.
  2. 컷은 정박, 글자는 엇박. 하드 컷은 정박 8/21, 글자 팝인은 정박 2/23.
  3. 브레이크에서는 컷하지 않는다.
- 킥은 16분음 네 자리에 고르게 퍼져 있다(싱코페이션). 하이햇은 8분음 펄스다. 드럼 키트, 혼, 보컬 여부는 추정이다.

## 타이포
- 기능 카드: 헤비 컨덴스드 그로테스크, 대문자 높이 9–20%, 2–3줄, 6단어 이하. 색은 오렌지, 형광 연두, 흰 바탕 위 검정.
- 거의 전부 컷인이다(애니메이션 0프레임). 움직이는 건 peel(2–4프레임), 펀치인(1–3프레임), 커서뿐이고 페이드나 블러는 없다.
- 카드 하나당 1.0–2.7s. 단어 연타 간격은 0.08–0.17s.
- 엔드카드를 빼면 모든 카피가 앱이나 문서 안에 있다.

## Moments 50s에 가져올 것
1. 숨 고르기 → 드롭에 첫 Moments 화면을 하드 컷으로 넣는다. 제품이 처음 보이는 순간이 가장 크게 들린다.
2. 업로드는 peel 연타로 보여 준다. 사진 카드가 8분음마다 벗겨지며 쌓이다가 하나의 Moment로 묶인다.
3. AI 검색은 타이핑으로 보여 준다. 마지막 글자를 큰 히트에, 결과 컷을 다음 히트에, #E08566 선택 테두리를 그다음 히트에 둔다. 기능 하나 = 4박.
4. 카피는 UI 안에 넣는다: Moment 제목, 검색창, 댓글, 스티커.
5. 컷은 정박, 글자는 엇박. 한국어는 어절 단위로 1–2프레임씩 연타한다("사진은 / 따로, / 순간은 / 함께").
6. 조용한 댓글은 펀치인 3단(사진 → 말풍선 → 댓글 글자)으로 보여 준다. 조용함은 내용이 맡고, 에너지는 편집이 맡는다.
7. 브레이크에서는 컷 없이 워드마크를 띄운다. 스톱 직전 히트에 "Moments."를, 재진입 히트에 photo-moments.app을 넣고 무음 #241C18 엔드카드로 끝낸다.
8. 음악은 100–105 BPM 라이브 그루브로 하고, 강약은 편집으로 만든다. 다크 + 오렌지 단어 스왑의 모양은 TNhX1uR2vO8을 참고한다.
