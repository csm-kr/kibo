# 오케스트라 60s 레퍼런스: Google Photos "Best Picture" (2017)

- URL: https://www.youtube.com/watch?v=tOb_bgnk4dY (Google 공식, 2017 아카데미 중계 광고). 길이 65.14s: 본편 0–54.0s, 엔드카드 54.0–65.1s, 오디오는 60.0s에서 끝남.
- Runner-up: Apple "The Surprise"(2019, 약 3분, 할머니 사진을 모아 보여 주는 주제, "Married Life" 오케스트라 [2차 출처]); Google "Loretta"(2020, 추억 검색 UI, 피아노 [2차 출처]).
- 표기: [측정] 프레임과 캡처한 오디오에서 직접 잰 값, [추정] 해석, [2차 출처] 검색 결과만 근거. 오디오는 Aside 안에서 WebAudio → MediaRecorder로 캡처했고 영상과 ±0.1s 이내로 정렬함.

## 왜 Moments에 맞나
1. 사진 서비스가 "평범한 순간이 곧 작품"이라고 말하는 광고라 감정선이 같다.
2. 클라이맥스 전환이 Moments의 핵심 기능과 같은 모양이다. 결혼식 셀카 한 장(50.67s) → 같은 결혼식의 다른 사진 타일이 흐리게 깔림(51.42s) → 줌아웃으로 격자가 됨(51.6–53.4s) → 격자가 앱 화면 안으로 들어감. "따로 올린 사진이 하나의 Moment가 된다"를 설명 없이 보여 준다.
3. 16.1s의 "big reveal"이 혹등고래이고 음악 진입 히트와 맞물린다. Moments의 "고래" 검색 데모를 같은 자리에 둘 수 있다.
4. 세로, 정사각, 가로 영상이 모두 높이 77%로 화면 가운데에 놓인다. 여러 사람이 각자 다른 폰으로 올린 사진을 보여 주기 좋다.
5. 60초 안에서 오케스트라 빌드가 끝까지 완결된다.
6. 한계: 제품 UI가 52–54s 2초뿐이다. Moments는 중반에 UI 장면이 필요하다.

## 쇼트별 정리 (요약)
- 0–46.3s: 사용자가 찍은 영상 클립, 2–5s 길이, 모두 하드 컷. 내레이션(VO)이 장르 이름을 붙인다: comedy / drama / action / big reveal(고래, 16.1s) / song / villain / love story / thriller / rom-com / horror / foreign film.
- 46.33 / 47.25 / 48.08 / 48.92 / 49.75s: 사진 5장, 0.83–0.92s 간격 하드 컷.
- 50.67s 히어로 사진 → 51.42s 주변 타일 약 20% 불투명도로 등장 → 51.6–53.4s 줌아웃(52.0s에 최고 속도, 이후 감속) → 앱 화면.
- 54.0s 로고 → "Photos." → "For life." → 57.3s 로고가 왼쪽으로 밀리며 스토어 배지 등장. 각 요소는 0.5s 페이드, 1s 간격.

## 타이포
- 0–54s에는 화면 글자가 없다(VO만). 엔드카드는 흰 배경에 로고와 2단어 태그라인 두 박("Photos." / "For life."), 1s 간격.

## Moments 60s에 가져올 것
1. 클라이맥스 전환을 그대로 쓴다. 히어로 사진 0.9s 정지 → 같은 Moment의 다른 사진이 약 20% 불투명도로 깔림 → 줌아웃 → 실제 Moment 화면. 핵심 기능을 설명 없이 보여 준다.
2. 비율이 다른 사진을 같은 높이로 맞춰 #241C18 위 가운데에 둔다. 각자 다른 폰으로 찍은 사진이 의도된 갤러리처럼 보인다.
3. 음악 뼈대: 인트로 약 16s → 펄스 진입 → 고른 빌드 → 마지막 2.5s 스웰 → 로고의 주황 "."이 찍히는 프레임에 IV→I 해결 → 5–6s 여운. 브랜드가 결론처럼 들린다.
4. 약 16s 진입 히트에 AI 검색 결과를 띄운다. 기능 데모가 감정의 큰 순간이 된다.
5. 클라이맥스 2–3s는 자막 없이 비운다. 스웰이 말과 부딪히지 않아야 크게 들린다.
6. 편집 리듬: 장면 2–3.5s → 사진 0.83–0.92s 연속 컷 → 줌아웃. 컷은 가장 가까운 음악 액센트 ±0.1s 안에 둔다.
7. 카드 한 장에 2–4단어까지만 쓴다. 엔드카드는 로고 → 1s 뒤 태그라인 두 박 → CTA.
8. 장르 몽타주 일부를 UI 장면으로 바꾼다(검색, 조용한 댓글). 레퍼런스는 UI가 2초뿐이지만 Moments는 기능을 증명해야 한다.
