# Issues

Every problem we find in code, docs, UI or our own way of working goes here, so the same mistake is not made twice. Sessions do not remember each other; this file does. Rules made from repeated issues are in `docs/RULE.md`.

## How to use
- **Before work:** read `docs/RULE.md`, then the open issues for the area you touch.
- **New problem:** if a row already describes the same problem, add a `Seen` token there. If it is a different problem, add a row with the next id, one `Seen` token and status `open`.
- **Class** names the cause so repeats can be counted: for a broken written rule, the rule (`target-size`, `text-size`, `palette`); otherwise the root cause in kebab-case (`stale-path`, not "e2e_check broke"). Reuse an existing class whenever the cause is the same; read the class column before inventing a name.
- **Seen** is a list of tokens `MM-DD/<where>`, where `<where>` is `<phase>:<step>` in a harness run or `session` otherwise. Add a token only for a **new occurrence**: the problem appears in a new place (another file, screen or element), or comes back after it was fixed (then set the status back to `open`). Seeing an unfixed problem again is not a new occurrence. Several places found in one pass add one token.
- **Third occurrence:** count per class, adding the `Seen` tokens of every row with that class. When the count reaches 3, add a rule to `docs/RULE.md` and write its id in the `Rule` column of those rows.
- **User decides:** rows marked this way wait for the user. A session never decides them; if its step needs the decision, it sets the step `blocked` with the issue id.
- **Deferred:** the user decided to do it later; the row says what to do and what it touches. Treat it as open when that work starts.
- **Fixed:** set `Status` to `fixed MM-DD` and say how. Keep the row; the history is what lets us count repeats.
- Areas: `ui`, `docs`, `api`, `db`, `agent`, `harness`, `tooling`, `process`.
- Sev: **P0** broken, unsafe or disqualifying; **P1** rule violation; **P2** polish or minor. Fix P0 before anything else.
